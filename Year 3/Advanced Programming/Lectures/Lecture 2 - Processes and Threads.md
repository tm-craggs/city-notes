### Concurrent Processes

We structure complex systems as sets of simpler activities. Each is represented as a **sequential process**

Processes can overlap, or can be concurrent. This helps reflect the concurrency in the modern world. 

Designing concurrent software can be complex and error prone. A rigorous engineering lead approach is essential. 

### Lecture Content

Concepts: Processes - units of sequential execution
Models: Finite State Processes (FSP), Labelled Transition Systems (LTS)
Practise: Java Threads

### Modelling Processes

Models are described using **state machines**, known as LTS. These are described as as finite state processes (FSP) and analysed with the LTSA tool. 

LTS is graphical form, FSP is algebraic form.
