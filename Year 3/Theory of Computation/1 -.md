
### Alphabets

Alphabet - Finite set of symbols/characters used for encoding. 

Example: E = {0, 1}


### Strings

A string w over an alphabet E is a finite sequence of symbols in E

There is a special symbol for the empty string

E* = set of all string over E and the empty string

### Languages and Machines

Language is defined as a set of strings

A language L over an alphabet E is a set of strings over E. L is a subset of E*
